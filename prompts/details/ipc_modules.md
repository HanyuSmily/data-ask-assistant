# IPC 各模块知识背景

## 配网
方式：SmartConfig 广播、AP 热点、二维码、蓝牙、声波。
失败点：5G/2.4G 混频、SSID 含中文或特殊字符、密码含空格、AP 隔离、DHCP 池耗尽、设备仅支持 2.4G。
查：设备收到的 SSID/密码、DHCP 交互、重试次数、失败原因码。

## OTA
链路：下发 → 云端推包 → 设备下载 → 校验(MD5/SHA) → 写分区 → 重启 → 版本上报。
失败点：不支持断网续传、分区空间不足、低电中断、签名校验失败、升级后版本未上报、双分区切换失败变砖。
必查：断电/断网中断后能否恢复（最高频严重缺陷）。

## 音视频
链路：采集 → 编码(H.264/H.265) → 封装 → 传输 → 解码 → 渲染。
失败点：首帧耗时过长、花屏（丢包/I 帧丢失）、音画不同步、码率自适应异常、对讲回声啸叫。
指标：丢包率、RTT、抖动；关注 200ms/500ms/1s 延迟档。

## 夜视 / 红外
依据：环境照度阈值 + 光敏/传感器。
失败点：日夜切换临界抖动（反复切）、红外灯不亮、过曝过暗、切换瞬间全黑、彩色转黑白偏色。

## 移动侦测
两种实现：硬件 PIR、软件图像差分。
失败点：误报（光照变化、树叶、宠物）、漏报（远距离、小目标）、灵敏度档位无差异、侦测区域不生效。
验证：固定场景循环触发统计漏报率，构造干扰源统计误报率。

## 云存储 / 回放
链路：事件触发录像 → 上传 → 分片索引 → App 拉流回放。
失败点：断网续传丢片、事件标记时间轴错位、拖到卡顿、跨天索引缺失、套餐到期后历史不可见。
必查：断网 N 分钟恢复后录像完整性（时间轴 vs 实际时长）。

## 对讲
上行：App 采集 → 编码 → 传输 → 设备解码 → 喇叭。
失败点：单向无声、回声、啸叫、延迟 >500ms 可感、松手尾音被截断。

## 低功耗 / 唤醒
策略：PIR 唤醒、按键、定时、App 主动唤醒。
失败点：睡死无法唤醒、频繁误唤醒耗电、唤醒后联网慢、休眠丢配置。
指标：待机电流(uA)、唤醒成功率、唤醒到出图耗时。

## 云台
结构：步进电机 + 限位（光电/霍尔）。
失败点：限位失效堵转异响、预置位偏移、巡航中断、翻转后画面方向错、校准失败。
